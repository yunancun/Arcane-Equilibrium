### 2.3 The reachable, fail-closed gate (mirror §6)

Replace the dead short-circuit at
`apply_observer_bootstrap` (currently lines 1333–1343: `if target_class == production or
disposable is None: return build_pending_result("… deferred to the S2.0 EFFECT session …")`)
with a typed production branch that mirrors the §6 `apply_s2_4_install_plan` order. Add a
keyword-only `driver: ObserverBootstrapProductionDriver | None = None` parameter (the
`disposable` cursor parameter stays for the logic-proof path):

```text
production branch order (fail-closed; each step returns a typed non-success on failure):
 1. validate intent schema + canonical digests + intent_id/self_digest idempotency binding
 2. verify source_head is 40-hex == intent.source_head; target_class==production;
    target_host is the attested Linux host (not Mac/dev)
 3. verify a FRESH domain-separated operator SSHSIG over the exact intent+source_head
    (identity/namespace = §2.2; TTL <= 15m; clock skew <= 60s) — an S1 target-host- or
    S2.4-namespace signature is rejected here on namespace/identity mismatch
 4. verify pre-state/dependency: observer role must be ABSENT (§5.3 pre-existing-state — no
    adoption/rotation of a pre-existing role), grant set == structured allowlist
    observer_read_only_v1, observed_relations include learning.alr_consumer_events (§2.2)
 5. if driver is None  -> EXTERNAL_VERIFICATION_PENDING, ZERO mutation   (Mac / tests / no host)
 6. driver present: obtain the driver's non-serializable, local-only PG admin handle
    (never a DSN string, never raw SQL); capture pre-state digest; require observer absent
 7. call the typed driver's fixed operations (create role + grants); NO caller SQL/unit/role text
 8. independent postcheck by the DISTINCT verifier node re-observes the role/ACL on the cluster
 9. emit immutable pg_observer_bootstrap_result_v1(status=APPLIED,
    production_apply_performed=true, nine_authorities_false=true) ONLY when the driver returns
    PLATFORM-attested apply+postcheck evidence; otherwise typed non-success, no success claim
```

Fail-closed table (S2.0 analog of §6):

| Condition | Result |
|---|---|
| production driver unavailable on Mac/tests (`driver is None`) | `EXTERNAL_VERIFICATION_PENDING` (zero mutation) |
| SSHSIG missing / stale / wrong namespace / wrong source_head | `EXTERNAL_VERIFICATION_PENDING` (existing `build_pending_result`) |
| observer role already exists (unowned pre-state) | `EXTERNAL_VERIFICATION_PENDING` (refuse create/drop — existing guard, lines 1354–1362) |
| disposable_local + valid SSHSIG (throwaway cluster) | `APPLIED_ROLLED_BACK_EXACT` (existing logic proof — unchanged) |
| production + real host driver + all checks + attested postcheck | `APPLIED` (new; **only** the real Linux driver may emit) |

**Only the real Linux driver may emit `APPLIED`.** A test-injected fake driver cannot fabricate
the PLATFORM-attested apply/postcheck evidence the builder requires before it sets
`production_apply_performed=true` (evidence-assurance model in CLAUDE.md: runtime authenticity
needs `PLATFORM_OR_EXTERNAL_ATTESTED`); a simulation/disposable driver's `LOCAL_REPRODUCIBLE`/
`STRUCTURAL_ONLY` evidence keeps the production flag false. Unlike the disposable path,
production does **not** roll the observer role back — it is left provisioned for S2.1 (§2.2 of
the contract); rollback authority is retained for failure/compensation only.
